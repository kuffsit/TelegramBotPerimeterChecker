# 🛡️ Веб-панель сканера безопасности

Современная веб-панель для управления сканированием безопасности с поддержкой ролевой модели, геолокации, планировщика и аналитики.

## 📁 Структура проекта

```
TelegramBotPerimeterChecker/
├── security-scanner/          # Основное приложение
│   ├── src/                   # Исходный код
│   │   ├── scanner/          # Оригинальный сканер
│   │   │   ├── core/         # Основные модули
│   │   │   ├── utils/        # Утилиты
│   │   │   └── reports/      # Генерация отчетов
│   │   └── web/              # Веб-приложение
│   │       ├── backend/      # FastAPI backend
│   │       └── frontend/     # React frontend
│   ├── data/                 # Данные сканирований
│   ├── reports/              # HTML отчеты
│   ├── logs/                 # Логи приложения
│   ├── scripts/              # Вспомогательные скрипты
│   ├── docs/                 # Документация
│   ├── docker-compose.yml    # Docker конфигурация
│   ├── Dockerfile.backend    # Backend образ
│   ├── Dockerfile.frontend   # Frontend образ
│   ├── .env.example          # Пример переменных окружения
│   └── README.md             # Подробная документация
└── README.md                 # Этот файл
```

## 🚀 Быстрый старт

### 1. Перейдите в директорию приложения
```bash
cd security-scanner
```

### 2. Настройте переменные окружения
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими настройками
```

### 3. Запустите приложение
```bash
# Автоматический запуск
./scripts/start.sh

# Или вручную
docker-compose up -d
```

### 4. Откройте веб-интерфейс
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs

## ✨ Возможности

### 🔍 Сканирование
- **Subfinder** - поиск субдоменов
- **Nmap** - сканирование портов  
- **Nuclei** - поиск уязвимостей
- **Прогресс в реальном времени**
- **Остановка активных сканирований**

### 📊 Аналитика и отчеты
- **Дашборд с метриками** и статистикой
- **Графики уязвимостей** по времени
- **Сравнение сканирований** между запусками
- **Экспорт отчетов** в PDF, Excel, CSV
- **Просмотр HTML отчетов** в браузере

### 🌍 Геолокация
- **Интерактивная карта мира** (React Leaflet)
- **IP → координаты** (GeoIP2 + ip-api.com)
- **Статистика по странам/городам**
- **Кэширование геоданных**

### ⏰ Планировщик
- **Автоматические сканирования** (APScheduler)
- **Cron-выражения** для расписания
- **Управление расписаниями** в веб-интерфейсе

### 🔐 Аутентификация и роли
- **JWT авторизация** с ролевой моделью
- **Роли пользователей**: Auditor, Manager, Admin
- **Управление пользователями** через веб-интерфейс

### 🔄 Обновления
- **Автообновление** Subfinder, Nuclei
- **Проверка версий** инструментов
- **Статус обновлений**

## 📋 Полезные команды

```bash
# Просмотр логов
docker-compose logs -f

# Перезапуск сервисов
docker-compose restart

# Остановка
docker-compose down

# Обновление образов
docker-compose pull
docker-compose up -d

# Очистка данных
docker-compose down -v
```
