# 🛡️ Веб-панель сканера безопасности

Современная веб-панель для управления сканированием безопасности с поддержкой ролевой модели, геолокации, планировщика и аналитики.

## ✨ Возможности

### 🔐 Аутентификация и роли
- **JWT авторизация** с ролевой моделью
- **Роли пользователей**: Auditor, Manager, Admin
- **Управление пользователями** через веб-интерфейс

### 🔍 Сканирование
- **Subfinder** - поиск субдоменов
- **Nmap** - сканирование портов
- **Nuclei** - поиск уязвимостей
- **Прогресс в реальном времени**
- **Остановка активных сканирований**

### 📊 Аналитика и отчеты
- **Дашборд с метриками** и статистикой
- **Графики уязвимостей** по времени
- **Сравнение сканирований** между запусками
- **Экспорт отчетов** в PDF, Excel, CSV
- **Просмотр HTML отчетов** в браузере

### 🌍 Геолокация
- **Интерактивная карта мира** (React Leaflet)
- **IP → координаты** (GeoIP2 + ip-api.com)
- **Статистика по странам/городам**
- **Кэширование геоданных**

### ⏰ Планировщик
- **Автоматические сканирования** (APScheduler)
- **Cron-выражения** для расписания
- **Управление расписаниями** в веб-интерфейсе

### 🔄 Обновления
- **Автообновление** Subfinder, Nuclei
- **Проверка версий** инструментов
- **Статус обновлений**

## 🚀 Быстрый старт

### Требования
- **Docker** 20.10+
- **Docker Compose** 2.0+
- **4GB RAM** минимум
- **10GB** свободного места

### Установка

1. **Клонируйте репозиторий**
```bash
git clone <repository-url>
cd security-scanner
```

2. **Настройте переменные окружения**
```bash
cp .env.example .env
# Отредактируйте .env файл
```

3. **Запустите приложение**
```bash
docker-compose up -d
```

4. **Проверьте статус**
```bash
docker-compose ps
```

### Доступ к приложению

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs

## ⚙️ Конфигурация

### Переменные окружения (.env)

```env
# Telegram Bot (опционально)
TELEGRAM_TOKEN=your_bot_token_here
CHAT_ID=your_chat_id_here

# База данных
DATABASE_URL=sqlite:///./data/scanner.db

# JWT
SECRET_KEY=your_secret_key_here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Сканеры
SUBFINDER_PATH=/usr/local/bin/subfinder
NMAP_PATH=/usr/bin/nmap
NUCLEI_PATH=/usr/local/bin/nuclei

# Порты для сканирования
PORTS=80,443,8080,8443,3000,5000,8000,9000

# Уровни уязвимостей
SEVERITY_LEVELS=medium,high,critical
```

### Создание первого пользователя

По умолчанию создается пользователь `admin` с паролем `admin123`.

**⚠️ Обязательно смените пароль после первого входа!**

## 📱 Использование

### 1. Вход в систему
- Откройте http://localhost:3000
- Войдите как `admin` / `admin123`
- Смените пароль в настройках

### 2. Добавление доменов
- Перейдите в **Домены**
- Нажмите **Добавить домен**
- Введите домен (например: `example.com`)

### 3. Запуск сканирования
- Перейдите в **Сканирования**
- Нажмите **Запустить сканирование**
- Выберите домен и нажмите **Запустить**

### 4. Просмотр результатов
- Откройте **Дашборд** для общей статистики
- Перейдите в **Сканирования** для деталей
- Используйте **Геолокация** для карты сервисов

## 🐛 Устранение неполадок

### Частые проблемы

**1. Порты заняты**
```bash
# Проверьте занятые порты
netstat -tulpn | grep :3000
netstat -tulpn | grep :8000

# Остановите конфликтующие сервисы
sudo systemctl stop nginx
```

**2. Недостаточно памяти**
```bash
# Увеличьте лимиты Docker
# В docker-compose.yml добавьте:
deploy:
  resources:
    limits:
      memory: 2G
```

**3. Ошибки сканирования**
```bash
# Проверьте логи сканера
docker-compose logs backend | grep -i error

# Перезапустите backend
docker-compose restart backend
```
